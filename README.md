# Saffron – public files

This public repository holds only things the app and the stores need to reach without a login:

- `latest.json` – the file the app reads every time it opens, to tell people a new version exists
- `privacy.html` – privacy policy (English, Deutsch) – the address given to Google Play and the App Store
- `index.html` – small home / support page
- Releases – the downloadable Android APK (direct version)

Never put passwords, keys or private files here: everything in this repository is public.
